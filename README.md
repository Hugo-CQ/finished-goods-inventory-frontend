# 航标家庭仓库 Web

家用物品整理 APP 的只读 Web 端。页面自动使用固定家庭账号连接 Supabase，读取 `home_inventory_snapshots` 中的最新快照。

## 功能范围

- 仓库摘要：装载架、容器、物品种类、总数量和待关注事项。
- 装载架、容器、物品三种视图。
- 名称、编号、位置和备注搜索。
- 物品分类与状态筛选。
- 物品、容器和装载架详情。
- 响应式桌面与手机布局。

Web 端没有新增、编辑、删除、导入或上传能力。数据统一在 iPhone APP 中维护，然后从“设置 → Supabase 云同步”上传。

## 固定账号说明

固定账号和密码按家庭单用户需求内置在客户端中，不显示账号输入界面。Supabase 使用 publishable key 和普通 Auth 用户，未使用管理员密码、secret key 或 `service_role`。

客户端内置凭据可被查看或反编译，只适合个人家庭场景；若网站公开传播，应改为服务端认证或每人独立账号。
