# 航标家庭仓库 Web

家用物品整理 APP 的 Web 端。输入家庭访问密码后连接 Supabase，与 iPhone 共用带版本校验的库存资料。

## 功能范围

- 仓库摘要：装载架、容器、物品种类、总数量和待关注事项。
- 装载架、容器、物品三种视图。
- 名称、编号、位置和备注搜索。
- 物品分类与状态筛选。
- 物品、容器和装载架详情。
- 响应式桌面与手机布局。

Web 端支持编辑已有物品、容器和装载架层位。新增、删除、导入和照片上传仍在 iPhone APP 中完成。

## 数据保护

- 登录状态自动续期；临时断网保留会话，恢复连接后重试。
- 未保存的草稿保留在当前标签页的 sessionStorage，刷新或重新验证密码后可恢复。关闭标签页会清除这份临时草稿。
- 保存使用云端版本校验：不同字段的修改可自动合并，同一字段的冲突会停止保存并保留草稿。
- 容器不能放进自身或下级容器；保存期间锁定输入，避免新输入被完成回调清除。
- 本地检查：`npx tsc -p tsconfig.client.json`、`npm run lint`、`npm test`、`npm run build:pages`。

## 固定账号说明

网页使用固定家庭账号和用户输入的访问密码；密码不写入网页源代码。会话仅存放在当前标签页中。Supabase 使用 publishable key 和普通 Auth 用户，未使用管理员密码、secret key 或 `service_role`。

iPhone 端仍采用原有的家庭单账号自动连接方式，只适合个人家庭场景；如需多人独立权限，应另行设计成员账号和授权。
